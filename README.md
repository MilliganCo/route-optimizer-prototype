# Route Optimizer Prototype

## Описание

Небольшое desktop-приложение на `tkinter` для расчёта стоимости и времени доставки на основе набора товаров, клиента, склада и транспорта. Проект оформлен как учебный или прототипный калькулятор логистических сценариев.

## Что делает

- хранит тестовые данные по товарам, складам, клиентам и транспорту;
- позволяет выбрать параметры доставки через GUI;
- оценивает стоимость маршрута;
- показывает ориентировочное время перевозки.

## Стек

- Python
- tkinter
- pandas

## Запуск

```bash
pip install pandas
python main.py
```
